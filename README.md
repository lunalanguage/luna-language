# 🌙 Luna Programming Language (v0.1)

Luna — это легковесный, интерпретируемый язык программирования, созданный для быстрого старта, работы с нейросетями и создания оконных приложений. Проект написан на чистом C++, не требует установки сторонних библиотек и компилируется в один компактный исполняемый файл.

*   **Zero-dependency:** Взаимодействует напрямую с WinAPI и WinINet без тяжелых фреймворков.
*   **Двуязычность:** Лексер поддерживает написание кода на русском и английском языках в одном файле.
*   **Native GUI:** Создание графических интерфейсов Windows без изучения сложного C++ кода.
*   **AI-Ready:** Встроенные HTTPS-запросы и автоматический парсинг ответов генеративных нейросетей.

---

## 🚀 Установка и запуск

1. Скачайте актуальный бинарный файл `luna.exe` из раздела **Releases**.
2. Поместите файл в любую удобную директорию и добавьте её путь в системную переменную среды `PATH`.
3. Создайте файл с расширением `.lun` и запустите скрипт в командной строке:
   `luna script.lun`

## 📚 Синтаксис и команды

Язык поддерживает динамическую типизацию (строки, числа), массивы и стандартные математические операции (`+`, `-`, `*`, `/`). Ниже представлена таблица встроенных команд:

| Категория | Команда (RU / EN) | Описание |
| :--- | :--- | :--- |
| **Ввод/Вывод** | `ввод` / `input`, `вывод` / `print` | Чтение из консоли и печать данных. |
| **Условия** | `если` / `if`, `иначе` / `else`, `конец` / `end` | Ветвление логики скрипта. |
| **Циклы** | `пока` / `while` | Выполнение блока кода по условию. |
| **Функции** | `функция` / `func`, `возврат` / `return` | Создание пользовательских подпрограмм. |
| **Сеть** | `запрос()` / `get()`, `пост()` / `post()` | Отправка HTTPS-запросов к API серверам. |
| **Нейросети** | `ответ_ии()` / `ai_text()` | Извлечение чистого текста из JSON-ответов ИИ. |
| **Графика** | `окно()`, `надпись()`, `кнопка()` | Отрисовка базовых элементов GUI по координатам. |
| **Запуск GUI** | `старт_окна()` / `run_gui()` | Системный цикл удержания окна (обязательно в конце). |

> **Примечание:** Язык автоматически управляет кодировками (CP1251 <-> UTF-8) и отсекает служебные BOM-байты, что делает его устойчивым к работе со стандартным Блокнотом Windows.

## 💻 Практические примеры

**Создание графического интерфейса:**
```text
window("Luna App", 400, 300)
label("Привет, мир!", 150, 50, 150, 30)
button("Нажми меня", 120, 100, 150, 40)
run_gui()
```
Обращение к нейросети (Gemini API):
```text
сервер = "generativelanguage.googleapis.com"
путь = "/v1beta/models/gemini-2.5-flash:generateContent?key=ВАШ_КЛЮЧ"
тело = "{\"contents\": [{\"parts\":[{\"text\": \"Назови цвет неба\"}]}]}"

ответ = пост(сервер, путь, тело)
вывод ответ_ии(ответ)
```
